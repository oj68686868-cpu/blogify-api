## ⚙️ Required Environment Variables
To run this project locally, create a `.env` file in the root directory and add:

- PORT
- MONGO_URI
- BASE_URL

Example:
```env
PORT=8010
MONGO_URI=your_mongodb_connection_string
BASE_URL=http://localhost:8010
